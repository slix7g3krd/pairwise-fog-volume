# pairwise-fog-volume

体积雾一进洞穴就整片发灰：froxel 深度按近平面线性切，远近精度差几十倍；点光注入把聚光锥当球算；半分辨率升采样双线性漏光；时域累积不按相机位移重投影，转身拖影；透明物体排在雾后；密度纹理三平面接缝；切近远平面不清历史；体积盒外仍采样内部密度；粒子雾与解析雾重复叠加；分屏共用一张 froxel 图。render/fog_volume.py 是核心，tests/test_fog_volume.py 15个红。要修的是：指数深度切片；聚光锥注入；深度感知升采样；重投影与历史校验；透明分层；三平面权重归一；远近平面临界清历史；盒内外密度门控；粒子与解析去重；分屏独立 froxel。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
